1. 퀵 정렬 후 배열이 정렬되어 있음
-퀵 정렬(Quick Sort)을 통해 배열이 오름차순으로 정렬되면, 이진 탐색은 그 정렬된 구조를 활용해 탐색 과정을 대폭 줄일 수 있습니다.
-순차 탐색은 배열이 정렬되었더라도 순서대로 하나씩 확인해야 하므로 정렬 여부와 상관없이 평균적으로 전체 요소의 절반에 가까운 비교가 필요합니다.
2. 탐색 방식의 차이
이진 탐색(Binary Search)
-분할 정복 알고리즘을 사용합니다.
    배열의 중간 요소를 확인한 뒤, 목표 값이 중간 값보다 크면 오른쪽 절반으로, 작으면 왼쪽 절반으로 탐색 범위를 좁힙니다.
-한 번의 비교로 탐색 범위를 절반으로 줄이므로, **탐색 시간은 대략 O(logN)**입니다.
-예를 들어, 크기 N=1000인 배열에서 이진 탐색은 약 log 2(1000)≈10번의 비교로 목표 값을 찾을 수 있습니다.
순차 탐색(Linear Search)
-순차 탐색은 배열의 정렬 여부와 관계없이 첫 번째 요소부터 마지막 요소까지 하나씩 확인해야 합니다.
-평균적으로 배열의 절반 정도(N/2)를 탐색해야 하므로 **탐색 시간은 O(N)**입니다.
-예를 들어, 크기 N=1000인 배열에서는 평균적으로 약 500번의 비교가 필요합니다.
3. 퀵 정렬 후 이진 탐색이 효율적인 이유
-퀵 정렬은 배열을 정렬하여 이진 탐색이 작동할 수 있는 전제 조건을 제공합니다.
-정렬된 배열에서는 이진 탐색이 목표 값을 빠르게 찾아내므로, 탐색 비교 횟수가 순차 탐색보다 훨씬 적습니다.
-순차 탐색은 정렬 여부와 관계없이 단순 반복적인 확인 작업을 수행하므로 비교 횟수가 많아집니다.

이처럼 정렬 상태와 탐색 알고리즘의 효율성 차이로 인해, 퀵 정렬 후 이진 탐색은 순차 탐색보다 적은 비교로 목표 값을 찾을 수 있습니다.
